🔐 CfdmNote — Como usar no Linux

Guia rápido · Versão 2.2.0 · Sem conhecimento técnico necessário

O que você tem

O arquivo CfdmNote-2.2.0-linux-x86_64.AppImage é o aplicativo completo numa caixinha. Não precisa instalar nada — tudo já está dentro dele.

Como abrir pela primeira vez

1
Coloque o arquivo numa pasta fácil de achar Por exemplo: Área de Trabalho ou uma pasta chamada Aplicativos.
2
Dê permissão para o arquivo abrir Clique com o botão direito → Propriedades → aba Permissões → marque "Permitir execução como programa".
💡 Só precisa fazer isso uma única vez.
3
Dê dois cliques no arquivo O CfdmNote vai abrir. Se aparecer uma pergunta, escolha "Executar".
4
Crie sua senha na primeira vez O app vai pedir uma senha para proteger seus dados. Escolha uma que você vai lembrar e anote num lugar seguro.
⚠️ Se errar a senha 10 vezes, os dados são apagados por segurança.

Se não abrir com dois cliques

Abra o terminal, vá até a pasta onde está o arquivo e digite:

./CfdmNote-2.2.0-linux-x86_64.AppImage

Usar no pendrive

✅ Copie o arquivo para o pendrive normalmente. Em qualquer computador Linux, repita os passos 2 e 3. Funciona igual — sem instalar nada.

Dúvidas frequentes

O arquivo tem 41 MB — é normal?
Sim. Tudo que o app precisa está dentro dele, por isso é maior.
Precisa de internet?
Não. Funciona completamente sem internet.
Como faço backup dos meus dados?
Menu CfdmNote → Backup Externo para salvar num pendrive ou HD externo.
Como abro o manual do app?
Pressione F1 dentro do app.
