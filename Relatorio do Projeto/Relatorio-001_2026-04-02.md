## O que é

CfdmNote = KeePassXC completo (C++17 + Qt5) + notas Markdown integradas (estilo Obsidian).
A interface do KeePassXC é preservada 100%. Todas as funcionalidades extras são adicionadas de forma não invasiva via QDockWidget, QTabWidget e menus adicionais.
